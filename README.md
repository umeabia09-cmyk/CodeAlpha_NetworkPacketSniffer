# CodeAlpha Network Packet Sniffer

## Overview

This project was developed as part of my CodeAlpha Cyber Security Internship.

The project implements a basic network packet sniffer using Python and the Scapy library. It captures network packets from an authorized lab environment and displays useful packet information for learning and analysis.

## Objectives

- Capture network packets using Python and Scapy.
- Identify common network protocols.
- Display source and destination IP addresses.
- Display TCP and UDP port information.
- Analyze packet and payload sizes.
- Store captured packet information in a CSV file.
- Understand basic network traffic and protocol behavior.

## Features

- Real-time packet capture
- Source IP identification
- Destination IP identification
- TCP, UDP and ICMP protocol detection
- Source and destination port detection
- Packet length analysis
- Payload length analysis
- CSV logging
- Timestamped packet records

## Technologies Used

- Python 3
- Scapy
- CSV
- Linux/Kali Linux
